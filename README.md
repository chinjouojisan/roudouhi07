# カコモと学ぶ 決算チャレンジ 労働費編

加古川市 令和7年度決算のうち「労働費」(決算総額 約2億360万円、11款中最小)を題材にした、クイズ+予算判断シミュレーションのPWAです。

## 構成

- `index.html` — 本体(単一HTMLファイル、データはJSONとしてページ内に埋め込み済み)
- `manifest.json` — PWAマニフェスト
- `sw.js` — オフラインキャッシュ用の最小限のService Worker
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — アイコン(款名の文言なし、全款共通)
- `og-image.png` — SNSシェア用画像(労働費版、本款専用)
- `extract_pdf_tables_roudo.py` / `process_pdf_tables_roudo.py` — 再利用スクリプト

## 内容

- **①入口クイズ**: 全11問(基礎知識5問+予算vs決算3問+特別トリビア3問)、全問2択形式
- **②本編シミュレーション**: 全3事業(すべて裁量事業、法定給付事業なし)を1件ずつ見ながら増額・維持・減額・廃止を判断
- **③答え合わせ**: 議事録公開待ちのため未実装

## この款の特徴

- 3事業(シルバー人材センター助成事業・雇用促進就職支援事業・勤労者住宅資金融資対策事業)で決算総額の約88%をカバーしており、他の款に比べてカバー率が高い
- kessan_meisaiとの突き合わせでは、事業一覧に出てこない大口支出や不自然なベンダー集中は見つからず、「気になる点」に該当する事項はなし
- 特別トリビアはすべて「件数と金額のギャップ」に着目した理由問い(奨学金返還支援の1人あたり単価減少、シルバー人材センターの契約件数未達×金額ほぼ達成、住宅資金融資の新規停止中でも予算=決算100%執行の理由)

## 公開時の作業

`index.html`冒頭のOGP用URL(`kessan-challenge/roudo/`の部分)を、実際の公開先パスに合わせて書き換えてください。
